# Notas_CCTV
Este es un pequeño repositorio acerca de mis notas acerca del mundo del CCTV.
El mundo del CCTV es muy extenso, independientemente de que sí te dediques a la programación u redes.
Con el avance de esta rama se ha facilitado la forma de instalar camaras de seguridad, frentes de calle y alarmas.
Aunque dependiendo del presupuesto del cliente se debe realizar los ajustes necesarios.
En este repositorio se mostrará todo referente a este campo y algunos consejos para realizar buenas instalaciones.
